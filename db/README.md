# db/ — сайт хамааралтай өгөгдлийн сангийн харагдацууд

Эдгээр файл нь **mevent.mn ажиллахад шаардлагатай** Postgres харагдацуудын эх бичиг.
Сайт өөрөө хүснэгтээс уншдаггүй — зөвхөн доорх харагдацаас. Тиймээс эдгээр
харагдац байхгүй бол сайт бараагаа харуулж чадахгүй.

## Яагаад репод байх ёстой вэ

Дүрэм зөвхөн VPS дээр байсан бол:

- VPS дахин байгуулбал **дүрэм алга болно** — нөөц хуулбарт нь ямар SQL байсныг
  хэн ч мэдэхгүй.
- Дүрэм өөрчлөгдсөн түүх хаана ч үлдэхгүй (git-д байвал үлдэнэ).
- Шинэ агент «сайтад юу харагдах вэ» гэдгийг кодоос хайж, олохгүй.

⚠ Эдгээр файл **автоматаар хэрэгждэггүй.** Гараар ажиллуулна (доор). Файл ба
амьд харагдац хоёр зөрж болно — тиймээс амьд ЗАН ҮЙЛИЙГ өдөр тутмын харуул
шалгадаг: `chimun-tasks` репогийн `tools/contract-check.js`.

## Файлууд

| Файл | Юу вэ | Хэн уншдаг |
|---|---|---|
| `public_catalog.sql` | «Сайтад юу харагдах» дүрэм + сул нөөц + багцын үлдэгдэл | `index.html`, `build-seo.js`, `build-products-json.js` |
| `app_config_public.sql` | Тариф / ангиллын бүлэг / түрээсийн давтамж (3 түлхүүр) | `index.html` |

`public_availability` (идэвхтэй түрээс) нь аппын репод —
`chimun-tasks/db/public_availability.sql`. Тэр харагдац аппын нөөц эзлэх
шатуудтай хамт өөрчлөгддөг тул тэнд байх нь зөв.

## Ажиллуулах

```bash
ssh chimun-vps 'docker exec -i vps-deploy-postgres-1 psql -U chimun -d chimun -v ON_ERROR_STOP=1' < db/public_catalog.sql
```

Файл бүрийн төгсгөлд шалгах болон буцаах тушаалууд бичээстэй.

## Дүрэм өөрчлөх

«Сайтад юу харагдах» дүрмийг өөрчлөх гэж байвал:

1. `db/public_catalog.sql`-ыг зас.
2. Ажиллуул (дээрх команд).
3. `node build-seo.js && node build-products-json.js` — хуудас, sitemap шинэчилнэ.
4. `node test/logic.mjs` — 122 тест.

**Сайтын JavaScript дотор шүүлт БҮҮ нэм.** Тэр дүрэм өмнө нь 3 газарт 3 өөрөөр
бичигдэж (сайт 196, SEO 190, апп 196 бараа) байснаас «аппад бараа хадгалахад
сайтаас чимээгүй алга болдог» алдаа төрсөн. `test/logic.mjs` одоо үүнийг хаадаг.

## Гарц

⚠ `create or replace view` нь баганыг зөвхөн **төгсгөлд** нэмж чаддаг. Дунд нь
оруулбал `cannot change name of view column` алдаа гарна. Багана нэмэх бол
жагсаалтын хамгийн сүүлд бич.

⚠ `security_invoker`-ыг **зориуд тавихгүй**. Харагдац эзнийхээ эрхээр үндсэн
хүснэгтийг уншина — ингэснээр `products` хүснэгтийг нийтээс бүрэн хаасан ч сайт
ажиллана.
